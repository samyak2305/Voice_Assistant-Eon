# 🤖 Eon – AI Voice Assistant

## 📌 Overview

Eon is a Python-based voice assistant that activates using the wake word **“Eon”** and executes voice commands. It can open websites, play music, fetch news, and generate AI-powered responses using the OpenAI API.

---

## 🚀 Features

* 🎙️ Wake word activation (“Eon”)
* 🗣️ Voice command recognition
* 🔊 Text-to-Speech responses
* 🌐 Opens:

  * Google
  * Facebook
  * YouTube
  * Instagram
* 🎵 Plays songs from custom music library
* 📰 Fetches latest news headlines
* 🤖 AI-powered responses using OpenAI
* 🔁 Continuous listening system

## ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/samyak2305/Voice_Assistane-Eon.git
cd Voice_Assistane-Eon
```

### 2️⃣ Install dependencies

```bash
pip install speechrecognition pyttsx3 requests openai pocketsphinx
```

### 3️⃣ Add API Keys

Replace:

* `YOUR-API-KEY` (OpenAI)
* `YOUR-API-KEY` (News API)

---

## ▶️ Run the Assistant

```bash
python main.py
```
